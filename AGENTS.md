# Consignes de contribution

- Lire l'issue, le README du module et les contrats concernés avant de coder.
- Une branche courte par tâche ; annoncer les fichiers concernés. Préserver le travail existant.
- Le prototype et ses tests sont dans `1-Derushage/`. Les autres étapes ne sont pas encore importées.
- Ne jamais ajouter de clés, configuration locale, rushs, exports, binaires ou caches.
- Garder les changements ciblés, avec des commits explicites : feat:, fix:, test:, docs:, chore:.
- Exécuter les vérifications du README et indiquer les tests ignorés ou non exécutés.
- Documenter les limites et livrer une PR lisible. Revue humaine avant fusion dans main.
- Ne pas force-push main. Utiliser revert pour une annulation partagée.
