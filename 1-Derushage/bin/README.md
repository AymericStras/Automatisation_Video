# Outils médias locaux

Placer ici FFmpeg et FFprobe, ou les installer dans PATH. Les variables
FFMPEG_PATH et FFPROBE_PATH permettent aussi d'indiquer leurs chemins.
Les exécutables ne sont pas versionnés. Conserver avec toute copie locale
sa licence et sa provenance. Le code Python n'a aucune dépendance externe.
